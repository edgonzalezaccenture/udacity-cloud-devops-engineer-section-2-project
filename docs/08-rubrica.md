# Rúbrica

Criterios con los que se evalúa el proyecto.

## Archivos del sitio web

| Criterio | Requisitos de presentación |
|---|---|
| El estudiante ha creado un bucket S3. | El bucket S3 es visible en la consola de administración de AWS. |
| Todos los archivos del sitio web deben agregarse al bucket S3. | El estudiante envió una captura de pantalla que muestra todos los archivos del sitio web cargados en el bucket S3 recién creado. |
| La configuración del bucket debe admitir el alojamiento de sitios web estáticos. | El bucket S3 está configurado para admitir alojamiento de sitios web estáticos. |
| Se debe configurar el permiso de acceso al bucket. | El bucket debe permitir el acceso público. Tiene una política de bucket de IAM que hace que su contenido sea de acceso público. |

## Distribución del sitio web

| Criterio | Requisitos de presentación |
|---|---|
| El sitio web debe distribuirse a través de CloudFront. | CloudFront se ha configurado para recuperar y distribuir los archivos del sitio web. |

## Acceso desde el navegador web

| Criterio | Requisitos de presentación |
|---|---|
| ¿El sitio web es de acceso público? | El sitio web debe ser accesible para cualquier persona en Internet a través de un navegador. El estudiante debe haber proporcionado la URL del nombre de dominio de CloudFront y la URL del punto de enlace del sitio web. |

## Sugerencias para que tu proyecto destaque

- Personaliza el sitio web cambiando parte del texto, por ejemplo el nombre de "Blog de viajes".
- Cambia la imagen de fondo para mostrar tu foto de vacaciones favorita en lugar de la que traen los archivos iniciales.
