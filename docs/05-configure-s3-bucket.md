# Configure S3 Bucket

1. Abre la pestaña **Propiedades** y baja hasta la sección **Alojamiento de sitios web estáticos**.
2. Haz clic en **Editar**, activa el alojamiento de sitios web estáticos e indica la página de inicio y la página de error del sitio.
3. En **Documento de índice** y en **Documento de error**, escribe `index.html` y haz clic en **Guardar**.
4. Vuelve a la sección **Alojamiento de sitios web estáticos** de la pestaña **Propiedades**: ya debe aparecer el punto de enlace del sitio web. Cópialo para usarlo más adelante.

Activar el alojamiento estático obliga a hacer público el bucket. La propia pantalla lo avisa: "For your customers to access the content at the website endpoint, you must make all your content publicly readable."
