# Proyecto: Implementar un sitio web estático en AWS

**El proyecto vence el 27 de noviembre de 2026.**

La nube es perfecta para alojar sitios web estáticos, que solo incluyen archivos HTML, CSS y JavaScript y no requieren procesamiento en el servidor.

1. Crear un bucket S3, configurarlo para el alojamiento del sitio web y protegerlo con políticas de IAM.
2. Cargar los archivos del sitio en el bucket y acelerar la entrega con CloudFront.
3. Acceder al sitio desde un navegador.

Hay que tomar una captura de pantalla del resultado de cada paso y enviarlas en una carpeta comprimida. La carpeta debe contener un `README.txt` con la URL del sitio web y cualquier otra información relevante para el equipo de revisión. El proyecto debe cumplir todas las especificaciones de la [rúbrica](08-rubrica.md).

## Lista de verificación antes de enviar

- Se cumplen todos los elementos de la rúbrica.
- El proyecto se ejecuta sin errores.
- Toda la funcionalidad requerida existe y se comporta como piden las especificaciones.
- La carpeta de envío incluye las capturas de pantalla requeridas.
- La carpeta de envío incluye un `README.txt` con la URL del punto de enlace de CloudFront.

## Recordatorio

Elimina o apaga todos los recursos de AWS (buckets S3, distribución de CloudFront, instancias EC2) inmediatamente después de que el proyecto se revise y se apruebe.
